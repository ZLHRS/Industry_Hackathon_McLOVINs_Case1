# Codex Multi-Agent Skills

These skills are intentionally compact operational playbooks. They complement the five custom agents and the portable toolbelt; they are not copies of general documentation.

## Skills

- `orchestration` — root-session routing, delegation, context packing, state and verification loop.
- `research` — evidence-first web/docs/GitHub/papers/integration research.
- `backend-engineering` — Python/FastAPI/API/database/async/reliability implementation.
- `frontend-engineering` — product-specific design, reference fidelity, React/TypeScript/UI/API implementation and rendered visual review; load the design and review references only when relevant.
- `ml-engineering` — datasets, experiments, training, inference, GPU and reproducibility.
- `verification` — independent correctness, regression, contract and evidence gate.
- `security-review` — secure-by-default review and targeted security checks.
- `tooling-and-diagnostics` — choosing and safely using the local toolbelt and optional MCPs.

Load only the skill(s) relevant to the current task. Prefer the smallest useful set.
