# Контроль результата профилактики

В разделе **«Отчёт»** мастер и руководитель могут раскрыть **«Контроль профилактики»**.
Блок показывает наряды, созданные из аналитических сигналов, и наблюдение после их
приёмки. Обычные плановые наряды без такого основания сюда не включаются.

1. Выберите период выдачи профилактических нарядов и примените фильтры.
2. Раскройте блок. Посмотрите состояние наряда и результат наблюдения.
3. При необходимости раскройте подробности и откройте исходные или повторные наряды.

Блок свёрнут по умолчанию и загружает данные только при раскрытии. Выдача, сдача
и приёмка нарядов остаются прежними. Контроль не создаёт задания и уведомления.

## Как понимать результат

| Состояние | Значение |
| --- | --- |
| Ожидает выполнения | Мастер ещё не закрыл профилактический наряд; сдача исполнителем сама по себе не начинает наблюдение |
| Отменён | Наряд отменён, результат профилактики не оценивается |
| Наблюдение продолжается | После подтверждённого закрытия мастером ещё не прошло семь дней; подходящих новых записей пока нет |
| Повтор зарегистрирован | После закрытия появился соответствующий внеплановый наряд; доступна ссылка на него |
| Повтор не зарегистрирован | Семь дней прошли без соответствующих записей |
| Недостаточно данных | Основание или закрытие нельзя надёжно подтвердить по журналу |

Для сигнала **повторной неисправности** сравнивается исходный шифр на той же машине.
Изменение шифра в профилактическом наряде не меняет цель наблюдения.
Для сигнала **поломки после ППР** отслеживаются любые новые внеплановые наряды на этой
машине. Интерфейс отдельно называет это внеплановым ремонтом, а не той же неисправностью.

Период отчёта относится к **выдаче профилактики**. Наблюдение идёт после её закрытия,
даже за пределами выбранного периода. Фильтр исполнителя или бригады не скрывает
последующие ремонты, назначенные другим сотрудникам. Отменённые, плановые и будущие
наряды не считаются повтором.

## Что это доказывает

Прослеживается цепочка **сигнал → профилактический наряд → приёмка мастером →
наблюдение за новыми записями**. Это дополнение к аналитике кейса, а не обещание
отдельных конкурсных баллов.

Отсутствие записи не доказывает исправность машины или причинный эффект профилактики.
Семь календарных дней не равны семи дням работы под нагрузкой. Для оценки экономии
нужны данные предприятия о наработке, простоях и стоимости отказов; здесь они не
выдумываются.

Сервер проверяет роли и доступ к участкам. Запрос только читает данные, не требует
миграции и не обращается к платной модели.
