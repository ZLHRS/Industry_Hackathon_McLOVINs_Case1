## Что показано в видео

Мастер выдаёт аварийный наряд и добавляет фото «до»; исполнитель принимает его,
начинает работу, сдаёт описание и фото «после». Мастер принимает результат с
обоснованием и оценкой, исполнитель видит обратную связь. В конце показаны
аналитика руководителя и семь разделов справочника администратора.

Видео снято на изолированной тестовой базе; изображения — синтетические схемы.
Внешняя модель в записи отключена намеренно: показан честный путь ручной приёмки
при её недоступности. Это не запись живого vision-анализа и не физический ремонт.
Результаты живой модели приведены отдельно в отчёте релиза. В видео используется
legacy seed с 100 нормативами; на публичном сайте — industrial seed с 51 нормативом.

Воспроизведение записи — Chrome/Edge/Firefox или другой проигрыватель WebM/VP8.
Сценарий записи: `scripts/record_demo.cjs`. Он работает только с отдельным стендом
на 58002/5178 и файлом `tmp/demo-server.json`; рабочую базу не затрагивает.

## Перед отправкой

Проведите репетицию выступления 3 минуты и вопросов 3 минуты. Заполните протокол
Android/PWA на 2–3 устройствах; эмуляция ширины экрана его не заменяет. Проверьте
доступность сайта с мобильной сети и откройте PDF и видео локально на запасном
компьютере. Материалы подготовлены; отправку организаторам команда выполняет сама.

В исходных документах есть расхождение дат. Для планирования принят более ранний
срок: **8 октября 2026, 23:59**; часовой пояс срока и порядок подачи уточняются у
организаторов. Полная матрица источников — [требования](../requirements.md).
