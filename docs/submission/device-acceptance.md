# Протокол проверки на устройствах

Это бланк измерения, не заявление об уже выполненных тестах. Браузерные результаты
приведены отдельно в отчёте релиза. Не вписывать расчётные значения как фактические.

| Проверка | Метод | Критерий | Факт и ссылка на запись |
| --- | --- | --- | --- |
| Выдача обычного наряда | С начального экрана мастера до подтверждения сервера, готовое задание, считать касания управляющих элементов отдельно от букв текста | ≤60 с и ≤6 касаний; описать способ подсчёта | ____ |
| Выдача аварийного наряда | То же, с аварийным приоритетом и выбранным оборудованием | Быстро и без ошибок; отдельно отметить фото/клавиатуру | ____ |
| Push в фоне | Свернуть установленную PWA, выдать наряд с другого устройства | Реальная доставка, звук, правильный наряд при открытии | ____ |
| Обновление статуса | Видеозапись двух устройств с часами, принять наряд | ≤5 с от подтверждения сервера до второго экрана | ____ |
| Фото | Снять разрешённый объект, сохранить исходный размер, выбрать мобильную сеть | ≤10 с до подтверждения загрузки; фото читаемо | ____ |
| Просрочка | Назначить короткий реальный срок, дождаться | Уведомление мастеру и исполнителю, полный контекст | ____ |
| Офлайн и возврат | Отключить сеть, выполнить разрешённое действие, перезапустить PWA, вернуть сеть | Очередь сохранена; действие выполнено один раз | ____ |
| Конфликт | Второе устройство меняет наряд до доставки первого действия | Явное сообщение, чужое изменение не затёрто | ____ |
| Выход | Выйти, открыть приложение без сети другим человеком | Нет доступных приватных данных предыдущего пользователя | ____ |
| Удобство | Мастер и исполнитель выполняют задание без подсказок разработчика | Записать ошибки, непонятные шаги, касания мимо кнопок | ____ |

Реальный производственный объект / фото допускается только с разрешения владельца.
Для оценки ИИ собрать независимый набор: исправлено / не исправлено / недостаточно
доказательств, разметка мастером до просмотра модели, отдельные фото разных ремонтов.
Отдельно считать ложную приёмку и лишние возвраты; повторные кадры одного ремонта
не должны оказаться одновременно в настройке и независимой проверке.
