# Похожие ремонты

Мастер может посмотреть опыт прошлых ремонтов, не выходя из формы выдачи наряда.

1. Выберите оборудование и опишите неисправность. Если шифр известен, укажите его.
2. Раскройте **«Похожие ремонты»** под описанием.
3. Откройте подходящий номер: проверьте основание совпадения, выполненные работы,
   материалы и наблюдение за повторными неисправностями.
4. Продолжите обычную выдачу. Подсказка не изменяет поля формы и не создаёт наряд.

Блок по умолчанию свёрнут; до раскрытия запрос истории не выполняется. Ошибка поиска
не мешает выдать наряд вручную. При изменении оборудования, описания или шифра старые
результаты перестают отображаться; поздний ответ не заменяет актуальную выборку.

## Откуда берутся результаты

Поиск показывает до трёх закрытых мастером нарядов за последние 365 дней в доступных
ему участках. Сначала рассматривается то же оборудование или оборудование того же
типа. Для попадания в результат нужен совпадающий шифр либо признаки неисправности
в тексте. Одного совпадения названия машины или общих слов «ремонт», «проверка» недостаточно.

У результата есть исходный номер и объяснение совпадения. Работы и материалы относятся
к принятой сдаче; расход из предыдущих попыток не подмешивается. Закрытие вручную
мастером также является решением человека — положительный вердикт внешней модели
для такого решения не требуется.

Выборка ограничена для предсказуемого времени ответа. При достижении ограничения
интерфейс предупреждает о неполноте поиска. Все проверки доступа выполняет сервер.
Поиск читает историю и не вызывает платный API языковой модели.

## Как читать наблюдение

Система ищет новые внеплановые наряды с тем же шифром на той же машине в течение
семи дней после закрытия ремонта. Отменённые наряды и будущие записи не учитываются.

- **Повтор зарегистрирован:** в периоде есть соответствующий наряд.
- **Повтор не зарегистрирован:** семь дней прошли, соответствующих записей нет.
- **Наблюдение продолжается:** семь дней ещё не прошли.
- **Недостаточно данных:** например, у ремонта нет шифра для сопоставления.

Это сведения из журнала, а не доказательство исправности машины, причины новой поломки
или эффективности ремонта. Отсутствие записи не гарантирует отсутствие отказа.
Исторический способ ремонта не является утверждённой технологической инструкцией;
мастер проверяет его применимость к текущему оборудованию и условиям.
