# НарядAI · McLOVINs

Проект для кейса №1 АО «Костанайские минералы» на QOSTANAI AI INDUSTRY HACKATHON 2026.
Мастер выдаёт наряд с телефона, исполнитель выполняет работу, система контролирует сроки,
а ИИ помогает проверить результат. Финальное решение остаётся за мастером.

**Текущее состояние: этап 1 — фундамент проекта. Это ещё не готовый MVP.**
Реализованы основа API, настройки, журнал HTTP-запросов и доменные правила статусов.
База данных, авторизация, мобильный интерфейс, фотографии, push и ИИ — следующие этапы.
Сервер пока предназначен для локальной разработки.

## Быстрый запуск

Основная среда — Ubuntu/WSL, Python 3.13.13 и uv.
Команды выполняются **в терминале Ubuntu**, из корня проекта:

```bash
cd /home/zlhrs/Industry_Hackathon
uv sync --locked
uv run --locked uvicorn naryadai.app:create_app --factory --host 127.0.0.1 --port 8000 --no-access-log
```

При необходимости скопируйте `.env.example` в `.env`, если файл ещё не существует.
uv создаёт `.venv` и использует версии из `uv.lock`; активировать окружение вручную не нужно.
Не используйте Windows Python для WSL `.venv`. Docker для этапа 1 не требуется.

- [Проверка процесса](http://localhost:8000/api/v1/health/live).
- [Документация API](http://localhost:8000/docs).
- Ответ: `{"status":"ok","service":"naryadai"}`. Остановка: Ctrl+C.

Liveness подтверждает работу процесса, а не готовность БД, ИИ или push.
Readiness появится вместе с инфраструктурой.
`--no-access-log` выключает стандартный журнал Uvicorn с полными URL;
журнал приложения сохраняет шаблон маршрута без query/body/персональных идентификаторов.

## Проверки

```bash
uv run --locked ruff check .
uv run --locked ruff format --check .
uv run --locked mypy
uv run --locked pytest --cov=naryadai --cov-report=term-missing
uv build
git diff --check
```

Те же проверки описаны в `.github/workflows/ci.yml`.
GitHub Actions ещё не запускался: отправку в репозиторий выполняет пользователь.
Предупреждения в тестах считаются ошибками; порог покрытия с учётом ветвей — 90%.
Покрытие относится к существующему коду, а не к проценту готовности всего кейса.

## Настройки

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `NARYADAI_ENVIRONMENT` | `development` | development / test / production |
| `NARYADAI_LOG_LEVEL` | `INFO` | Уровень JSON-журнала |
| `NARYADAI_ALLOWED_HOSTS` | localhost, 127.0.0.1, [::1] | JSON-массив host без портов |
| `NARYADAI_CORS_ORIGINS` | `[]` | JSON-массив точных origin |

Production скрывает Swagger/OpenAPI, запрещает DEBUG и HTTP CORS origins.
Это пока не означает готовность к промышленному развёртыванию.
Для доступа с телефона позже потребуются явно разрешённый host и HTTPS.
